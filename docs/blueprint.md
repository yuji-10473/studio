# **App Name**: Townfolk Tales

## Core Features:

- AI Character Interaction: Engage in conversations with AI-powered characters, influencing their mood through dialogue.
- Mood System: Implement a mood system that changes based on conversation content, affecting character responses.
- Virtue (Tok) System: Award 'Tok' points to players when they positively influence a character's mood above a threshold.
- Date Progression: Advance the game date by 'staying at an Inn,' resetting character moods and conversation history.
- Persona Editor: Real-time AI persona editing for characters via the UI, allowing immediate testing of dialogue changes.
- API Key Configuration: Implement a mechanism to set and use the Gemini API key, either through an environment variable or via UI input.
- Dynamic Character Introduction: The AI tool should include the 'introduction' attribute of the character when crafting the response.

## Style Guidelines:

- Primary color: Soft beige (#F5F5DC) to evoke a sense of warmth and old-world charm.
- Background color: Light grey (#F0F0F0) to create a clean and unobtrusive backdrop.
- Accent color: Dusty rose (#BC8F8F) for interactive elements and highlights, adding a touch of nostalgia.
- Headline font: 'Literata', a serif typeface for headers to bring a literary and vintage feel.
- Body font: 'Inter', a sans-serif typeface for body text to ensure readability and a modern contrast.
- Use simple, line-based icons to represent different actions and elements, maintaining a minimalist aesthetic.
- Design a card-based layout for character display, focusing on readability and ease of interaction.
